# Architecture decisions

Architecture Decision Records (ADRs) capture choices that are costly to reverse.
Accepted records form part of the development baseline.

- [ADR-0001: Native Qt architecture](0001-native-qt-architecture.md)
- [ADR-0002: Markdown source and project AST](0002-markdown-source-and-project-ast.md)

New records use `NNNN-short-title.md` and contain context, decision,
consequences, and status.
